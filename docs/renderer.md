# 描画の決めごと

作り直し（2026-10）で決めたことと、その理由。実装の案内は README に、API の詳細は各ファイルの型に書いてある。

## 決めたこと

- 図の定義（`src/model/diagram.ts`）には見た目を書かない。色はトーン名、形はノードの種類で指定し、実際の色・線・フォントは様式（`src/skins/`）が決める。様式を切り替えてもノードの列と行は変わらない。
- 時間は仮想時計 `t` だけ。`sampleAt(timeline, t)` は純粋関数で、同じ `t` なら同じ絵になる。`requestAnimationFrame` は `src/render/useTransport.ts` の中にしか無く、`Transport.tick(dt)` を呼ぶ以外のことをしない。`Math.random` と `Date.now` は描画経路で使わない。手描き線の揺らぎは要素 id から作った seed で固定する。
- 座標は手で置かない。レーン × 列 × 行で書き、`resolveLayout` が箱と折れ線を決める。直交ルータは同じ辺に入る線を幹線にまとめ、ループは外周を通す。線とノードの交差は `validateLayout` が警告にし、テストで落とす。
- 粒子は中身を持つ。ノードを通るたびに `payload` が変わり（質問、ベクトル、文書×3、プロンプト、回答）、変身は「縮んで入れ替わる」。透明度のクロスフェードはしない。
- 静止表示（一時停止、reduced-motion、PNG）は全ステップを 1 枚に畳む。辺ごとに粒子を 1 つ置き、辺にラベルがあれば粒子のラベルは出さない。
- 番号バッジは、ラベルの無い辺では画面の上側に置く。粒子のラベルが下に出るため。
- 投稿枠（4:5、9:16、1:1）の中では図を枠に合わせて拡大縮小する。縮小が 0.7 倍を切る図はテストで落ちるので、そのときは内容を減らすか行の高さを詰める。
- 書き出しは `?export=1` の素の描画を Playwright で 1 フレームずつ撮り、ffmpeg で MP4 にする。同じ引数で 2 回出すと PNG のハッシュが一致する。

## やめたこと

- SVG の `animateMotion`。実時間に縛られて書き出しとスクラブができない。
- `innerHTML` で粒子を描く方式。React 要素で描けば `renderToStaticMarkup` がそのまま書き出しに使える。
- Tailwind の既定色、Inter、ガラス、放射グラデーション、ぼかし。様式ごとに実物由来の色と日本語フォントを持つ。
- lucide の流用アイコン。図記号は `src/skins/icons.ts` に自前で描いた。

## 未解決

- レーンの境界に乗る辺ラベルとバッジがレーン見出しに重なることがある（agentic-rag の「道具を呼ぶ」）。
- 列間が約 86px しか無いので、短い辺にラベルを付けると箱に食い込む。ラベルは長い辺にだけ付けている。
- 8 枚の一覧は 4:5 では読めない。Instagram 向けはカルーセル（1 枚ずつ）にする。
